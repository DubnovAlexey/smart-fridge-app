# ❄️ Умный холодильник 2.0 (Smart Fridge)

**Умный холодильник** — это современное веб-приложение (PWA) для управления домашними запасами продуктов. Оно помогает семье сократить количество выбрасываемой еды, автоматизирует процесс составления списка покупок и использует искусственный интеллект для генерации рецептов из того, что прямо сейчас лежит на полках.

Проект разработан как полноценный SaaS-продукт с облачной базой данных, системой прав доступа и мультиязычным интерфейсом.

---

## 🚀 Основной функционал

* **Турбо-сканер штрих-кодов:** Автоматическое распознавание продуктов через камеру телефона с подтягиванием состава и идей для блюд из мировой базы OpenFoodFacts.
* **ИИ-Шеф-повар (Gemini AI):** Нейросеть генерирует рецепты на основе текущих остатков еды в холодильнике (функции "Из всего" и "Спасти продукты").
* **ИИ-Снабженец:** Анализирует рецепт желаемого блюда, сверяет его с вашим холодильником и автоматически добавляет недостающие ингредиенты в Корзину.
* **Умные сроки годности:** Приложение автоматически предлагает средний срок хранения продукта по ГОСТу при вводе названия.
* **Семейный доступ и Права (Делегирование):** Ролевая система (Админ, Юзер, Гость, Ребенок). Администратор может запрещать детям или гостям списывать продукты в мусор.
* **Система рейтинга блюд:** После того как продукт съеден, семья может оценить качество блюда по 5-звездочной шкале и оставить отзыв.
* **Мультиязычность и Мультивалютность:** Полный перевод интерфейса на лету (Русский, Иврит, Английский, Немецкий, Испанский) с поддержкой RTL (чтения справа налево) и выбора валюты (₽, ₪, $, €).
* **Аналитика и Экспорт:** Подсчет финансовых потерь от выброшенной еды и возможность выгрузки/загрузки базы данных в формате Excel (CSV).
* **Установка на телефон (PWA):** Приложение скачивается на рабочий стол смартфона в обход App Store / Google Play и может кэшировать ресурсы для быстрого запуска.

## 🧠 Техническая архитектура (Под капотом)

Проект построен на принципах Vanilla JavaScript (без использования тяжеловесных фреймворков), но с применением современных паттернов проектирования.

### 1. Паттерн MVC (Model-View-Controller)
Логика строго разделена на независимые слои, что предотвращает превращение кода в «спагетти»:
* **Модель (`models/Fridge.js`):** "Мозг" приложения. Хранит массивы данных, сортирует их и общается с сервером. Ничего не знает про интерфейс.
* **Представление (`ui/render.js`):** "Лицо". Только рисует HTML-карточки на основе полученных данных.
* **Контроллер (`app.js`):** "Дирижер". Слушает клики пользователя, передает команды Модели и просит Представление обновить экран.

### 2. Асинхронность и работа с сетью (Promises, async/await)
Для предотвращения "зависания" интерфейса при долгих вычислениях, все сетевые запросы выполняются в фоне. Приложение не блокируется, пока ждет ответ от базы данных или нейросети.

### 3. Интеграция сторонних API
* **Google Gemini AI:** Связь с нейросетью через REST API. Реализован сложный промптинг, заставляющий ИИ возвращать не просто текст, а строго структурированный формат `JSON` для автоматического парсинга списка покупок. ИИ настроен на генерацию ответов на выбранном языке интерфейса.
* **Firebase Firestore:** Облачная NoSQL база данных реального времени. Данные хранятся в виде защищенных коллекций документов.
* **Firebase Auth:** Изолированный модуль аутентификации, берущий на себя логику шифрования паролей и создания пользовательских сессий.

### 4. Событийно-ориентированная архитектура (Event Delegation)
Вместо того чтобы вешать обработчики кликов (`addEventListener`) на каждую из сотен кнопок "Взять" или "Списать", используется паттерн **Делегирования**. На весь холодильник вешается всего один слушатель, который через `event.target` и `dataset.id` определяет, какая именно кнопка была нажата. Это радикально экономит оперативную память браузера (Performance Optimization).

### 5. Принцип единого источника истины (Single Source of Truth)
Интерфейс (HTML) никогда не хранит состояние приложения. При любом действии (например, съели 2 яйца из 10), программа сначала обновляет данные в объекте Модели (`batches`), а затем полностью перерисовывает полку. Это на 100% исключает рассинхронизацию данных между сервером и экраном телефона.

### 6. PWA (Progressive Web App) и Service Workers
Написан файл `manifest.json` для конфигурации нативного отображения (иконки, скрытие строки браузера). Подключен `Service Worker`, который использует `Cache API` для сохранения скриптов и стилей в память телефона, обеспечивая мгновенный запуск. Добавлен скрипт обнаружения iOS-устройств (iPhone) для вывода пользовательских подсказок по установке, а также кнопка-инструкция для ручной настройки.
