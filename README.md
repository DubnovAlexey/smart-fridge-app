# ❄️ Умный Холодильник (Smart Fridge) - V2.0 Cloud Edition

## О проекте
Интеллектуальный веб-сервис для учета продуктов, минимизации пищевых отходов и генерации рецептов на базе ИИ. Версия 2.0 переводит проект в облако и превращает его в семейную социальную сеть для управления кухней.

## 🗺️ Roadmap (План развития V2.0)

### Этап 1: Облачная инфраструктура и Семейный доступ
- [ ] Миграция локальной базы (localStorage) на **Google Firebase (Firestore)**.
- [ ] Синхронизация данных в реальном времени между устройствами всей семьи.
- [ ] Индивидуальные профили пользователей (Папа, Оля, Ваня) со статистикой потребления.

### Этап 2: «Умные остатки» и Семейный рейтинг
- [ ] Трекинг готовых блюд (остатков еды) с расчетом короткого срока годности.
- [ ] Внутренняя соцсеть: система оценок (1-5 звезд) и комментариев к блюдам от домочадцев.
- [ ] Аналитика качества: рейтинг конкретных магазинов на основе отзывов семьи.

### Этап 3: Эволюция AI-Шефа (Gemini)
- [ ] Анализ запасов под конкретное желаемое блюдо (список покупок для того, чего не хватает).
- [ ] Интерактивная «Кулинарная книга» семьи (сохранение удачных рецептов от ИИ).
- [ ] ИИ-анализ предпочтений (нейросеть отсекает продукты с низким семейным рейтингом).

### Этап 4: Интеграция с реальным миром
- [ ] Автоматизация ввода: сканер штрих-кодов, распознавание чеков (OCR) и база ГОСТов.
- [ ] Интеграция по API с супермаркетами (Рами Леви, Кешет Теамим и аналоги).
- [ ] Авто-сборка корзины покупок в реальном магазине.

### Этап 5: Масштабирование
- [ ] Мультиязычность (i18n): поддержка RU, HE (с RTL-дизайном) и EN.
- [ ] Адаптация под PWA (установка приложения на главный экран смартфона).
