# ❄️ Умный холодильник (Smart Fridge) — v1.0 MVP

**Умный холодильник** — это современное веб-приложение для управления домашними запасами продуктов. Проект помогает минимизировать пищевые отходы (Food Waste), контролировать сроки годности и планировать меню с помощью искусственного интеллекта.

Текущая версия (1.0) представляет собой полнофункциональный MVP, работающий локально в браузере, с заложенной архитектурой для перехода на облачный бэкенд в Версии 2.0.

## 🌟 Ключевой функционал

*   **Управление продуктами (CRUD):** Добавление продуктов с точным указанием сроков годности (по дням или календарной дате), веса, цены и категорий.
*   **Умная сортировка:** Продукты, у которых истекает срок годности, автоматически поднимаются в верхнюю часть списка.
*   **Система ролей (RBAC):**
    *   *Пользователь* — полный доступ к продуктам.
    *   *Администратор* — доступ к системным настройкам и API-ключам.
    *   *Гость / Ребенок* — ограниченный доступ (с возможностью делегирования прав).
*   **AI-Шеф-повар (Gemini API):** Нейросеть генерирует рецепты на основе содержимого холодильника. Два режима: «Из всего, что есть» и «Спасти продукты». Реализована изящная деградация (Graceful Degradation) — резервные рецепты при сбоях API.
*   **Продуманный UI/UX:**
    *   Мобильные Toast-уведомления вместо системных alert().
    *   Графическое «Пустое состояние» (Empty State) при отсутствии продуктов.
*   **Экспорт и Импорт CSV:** Выгрузка базы продуктов и загрузка обратно с помощью кастомного парсера, устойчивого к кавычкам и сложным строкам.

## 🛠 Технологический стек

*   **Frontend:** HTML5, Vanilla JavaScript (ES6 Modules).
*   **Стилизация:** Tailwind CSS (через CDN для MVP).
*   **Хранение данных:** `localStorage` (с автоматической сериализацией JSON) и `sessionStorage` (для безопасного хранения токенов и сброса при выходе).
*   **Архитектура:** MVC (Model-View-Controller) с жестким разделением логики хранения, отрисовки и управления.

## 🚀 Запуск проекта

Проект не требует установки зависимостей или локального сервера.
1. Склонируйте репозиторий или скачайте архив.
2. Откройте файл `index.html` в любом современном браузере.
3. Для доступа к Панели Администратора выберите роль «Админ» и введите пароль: `admin2026`.
