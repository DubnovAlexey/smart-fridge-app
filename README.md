# ❄️ Умный холодильник (Smart Fridge) — v1.0 MVP

**Умный холодильник** — это современное веб-приложение для управления домашними запасами продуктов. Проект помогает минимизировать пищевые отходы (Food Waste), контролировать сроки годности и планировать меню с помощью искусственного интеллекта.

Текущая версия (1.0) представляет собой полнофункциональный MVP, работающий локально в браузере, с заложенной архитектурой для перехода на облачный бэкенд в Версии 2.0.

## 🌟 Ключевой функционал

*   **Управление продуктами (CRUD):** Добавление продуктов с точным указанием сроков годности (по дням или календарной дате), веса, цены и категорий.
*   **Система ролей (RBAC - Role-Based Access Control):**
    *   *Пользователь* — полный доступ к продуктам.
    *   *Администратор* — доступ к системным настройкам и API-ключам.
    *   *Гость / Ребенок* — ограниченный доступ (включается делегирование прав на взятие или списание продуктов).
*   **AI-Шеф-повар (Интеграция с Gemini API):** Нейросеть анализирует содержимое холодильника и генерирует 5-7 рецептов. Работает в двух режимах: «Из всего, что есть» и «Спасти продукты» (приоритет скоропортящимся запасам). Реализован механизм Graceful Degradation (резервные рецепты при недоступности API).
*   **Аналитика и Финансы:** Автоматический подсчет съеденных продуктов, списаний в мусор и финансовых потерь.
*   **Экспорт и Импорт CSV:** Возможность выгрузки базы продуктов в Excel и загрузки обратно (с кастомным парсером, устойчивым к сложным строкам и кавычкам).
*   **Fake Door Testing:** В интерфейс внедрены элементы Версии 2.0 (сканирование штрих-кодов, чеков, мобильное приложение) для сбора обратной связи и демонстрации вектора развития проекта.

## 🛠 Технологический стек

*   **Frontend:** HTML5, Vanilla JavaScript (ES6 Modules).
*   **Стилизация:** Tailwind CSS (через CDN для MVP).
*   **Хранение данных:** `localStorage` (с автоматической сериализацией/десериализацией JSON) и `sessionStorage` (для безопасного временного хранения API-ключей).
*   **Архитектура:** MVC (Model-View-Controller) с жестким разделением логики хранения, отрисовки и управления.

## 🚀 Запуск проекта

Проект не требует установки зависимостей, сборщиков (Webpack/Vite) или локального сервера (Node.js).
1. Склонируйте репозиторий или скачайте архив.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Safari, Firefox).
3. Для доступа к панели Администратора выберите роль «Админ (Настройки)» и введите пароль по умолчанию: `admin2026`.
